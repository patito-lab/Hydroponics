# 002: Nutrient Setup

**Date:** 28Jul26
**Status:** Accepted

## Context

Need to determine how to split up nutrients. Using MASTERBLEND combo kit, containing masterblend 4-18-38, Calcium Nitrate 15.5-0-0, and Epsom Salt. Also using pH up (potassium carbonate) and down (phosphoric acid) solution

## Options considered

considered using a individual vs multichannel peristaltic pumps, shared vs separate containers for nutrients, foregoing pH adjustments completely.

## Decision

Calcium nitrate and nutrient (4-18-38 + Epsom Salt) solutions are dosed on separate lines with no shared plumbing or mixing point upstream of the reservoir. Include pH up and down mixtures. 4 reservoir, 4 pumps, no shared pumps or lines

## Why

If mixed, nutrients would percipitate. pH up and down can't be mixed either without neutralizing. Separate lines used for the same reason. Separate pumps given finer control over dosing and allow for varying concentration of the solutions. Even though solutions would be separate with a multichannel peristaltic pump, it will dose at the same rate. Tubing size can be used to vary this, but it is a minor control and more complex.
